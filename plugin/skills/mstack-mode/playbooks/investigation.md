### Investigation

**You own the answer. Read-only: a cited explanation or recommendation, no code change.**

1. Route through the `how` skill. For motivation questions, also `why`.
2. Throughput checkpoint stays one line: `throughput checkpoint: n/a, read-only investigation`.
3. Produce the `how`-shaped output (Overview / Key Concepts / How It Works / Where Things Live / Gotchas), or for a decision between alternatives, a recommendation with a tradeoffs table.
4. Apply the unslop pass (`writing`) to the reply.

No PR, no babysit, no `architect`. If the investigation precedes a code change, hand back to the user and re-route to Bug fix or Feature.

**Reply:** the investigation output. For "are we sure?", give your real judgment with reasons and push back on a wrong premise (Autonomy).
