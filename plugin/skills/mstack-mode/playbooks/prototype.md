- Open design space: gather prior art; moodboard themes/palettes/layouts; let user pick. Skip if direction set.
- Build in an isolated scratch dir outside production. Visual: vanilla HTML/CSS/JS via CDN. Behavioral: smallest script. No production frameworks, tests, abstractions.
- Compare alternatives behind one labeled switcher (buttons or a keypress). For in-app components, use `<mstack>/skills/ui/references/prototype/index.md` to build behind its picker.
- Verify on matching surface: screenshot each variant and drive interaction; or observe/log timing/output/render. The observation is the test.
