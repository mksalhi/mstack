# Pick the mode first (Diátaxis)

One document, one mode. Don't mix modes; split and link.

Tutorial: learner success; start with what they will build; every step yields visible result; say what they should see; keep explanations to a clause + link; imperative, concrete steps.

How-to: solve a person's problem; assume competence; action only; link background; allow forks; title by task.

Reference: only describe; no instruction/persuasion/opinion; be complete and certain; state options/limits/errors; mirror the thing's structure; generate from code.

Explanation: one bounded topic; readable away from product; answer "why"; include design decisions, constraints, history, alternatives; opinion allowed only here.
