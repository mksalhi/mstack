# Catch up details

The rules in `SKILL.md` Catch up apply. These add to them.

## What happened
- Gather your work since the user's last message, subagent reports, and others' messages in this chat.
- Visuals first. Each bullet gives the result and status: done, running, failed, or unchecked.
- Then at most three lines that change what the user knows or must do, and one line on work left that you can do.

## Action items
- State the call (merge, approve, pick), with any prerequisite.
- Shared call: the call and pick once, then one bullet per item, riskiest first.
- Mention the cost of waiting only beyond delay.

## Visuals
- Draw only when a picture beats sentences. At most six boxes of eight words each, labeled in plain speech.
- Link only existing artifacts.
